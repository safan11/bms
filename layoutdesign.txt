============================================================
PART 1 - WHAT IS A WEB PAGE LAYOUT?
============================================================

Before writing Angular code, explain the idea of a layout.

A typical web application can be divided into different areas:

    +------------------------------------------------+
    |                    HEADER                      |
    +-------------------+----------------------------+
    |                   |                            |
    |      SIDEBAR      |        MAIN CONTENT        |
    |                   |                            |
    |   Dashboard       |   Employee Dashboard       |
    |   Employees       |                            |
    |   Departments     |   Employee information    |
    |   Reports         |                            |
    |                   |                            |
    +-------------------+----------------------------+
    |                    FOOTER                      |
    +------------------------------------------------+


HEADER
------
Usually contains:

    Application name
    Logo
    Top navigation
    User information


SIDEBAR
-------
Usually contains navigation:

    Dashboard
    Employees
    Departments
    Reports


MAIN CONTENT
------------
This is the main area where application information is displayed.

For example:

    Employee list
    Product list
    Dashboard
    Forms
    Reports


FOOTER
------
Usually contains:

    Copyright
    Company information
    Contact information


IMPORTANT IDEA:

Angular does not automatically create this layout.

We create the layout using:

    HTML
    CSS
    Angular Components

Bootstrap can later make the CSS/layout work much easier.

STEP 10 - CREATE THE MAIN LAYOUT CSS
============================================================

Open:

    app.component.css

    .layout {
        display: flex;
        min-height: 400px;
    }


This is the most important CSS in our layout.


WHAT DOES display: flex DO?
---------------------------

It allows elements to be arranged easily in a row or column.


We have:

    <div class="layout">

        <app-sidebar></app-sidebar>

        <app-main-content></app-main-content>

    </div>


Because .layout has:

    display: flex;


the two components appear next to each other:

    SIDEBAR | MAIN CONTENT


Without flex:

    SIDEBAR

    MAIN CONTENT


With flex:

    SIDEBAR | MAIN CONTENT


This is the basic idea of Flexbox.

============================================================
UNDERSTANDING BOOTSTRAP GRID
============================================================

This is important.

We wrote:

    <div class="row">


Inside:

    <div class="col-md-4">


Bootstrap uses a 12-column grid.

Think:

    12 columns
    +---+---+---+---+---+---+---+---+---+---+---+---+


If we write:

    col-md-4


it means:

    4 out of 12 columns.


So:

    col-md-4
    col-md-4
    col-md-4


gives:

    +------------+------------+------------+
    |            |            |            |
    |  Column 4  |  Column 4  |  Column 4  |
    |            |            |            |
    +------------+------------+------------+


4 + 4 + 4 = 12


This is one of the most useful Bootstrap concepts.

HOW TO EXPLAIN CSS TO BEGINNERS
============================================================

Do not start with complicated CSS theory.

Start with:

HTML = Structure

CSS = Design

Angular = Application logic + components


Example:

    <button>
        Add Employee
    </button>


HTML gives us:

    Button


CSS gives us:

    Color
    Size
    Spacing
    Position


Angular gives us:

    What should happen when button is clicked?


For example:

    <button (click)="addEmployee()">
        Add Employee
    </button>


Here:

    HTML
       ↓
    Button

    CSS
       ↓
    Button appearance

    Angular
       ↓
    Button behavior
